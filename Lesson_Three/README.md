## Overview

This portfolio serves as a centralized digital hub highlighting a multidisciplinary profile spanning **biochemistry, software development, medical hardware design, and product formulation**. Built with clean semantic markup and modern styling frameworks, it provides an intuitive user experience across mobile and desktop viewports.

---

## Key Features

* **Interactive Section Navigation:** Seamless layout transitions covering About, Experience, Education, Skills, Certifications, and Contact.
* **Responsive Grid Systems:** Custom CSS grid architectures for skill matrices and certification cards.
* **Professional Contact Integration:** Direct mail-to integration and styled social profile links (LinkedIn, GitHub, Twitter).
* **Multimedia Typography & Icons:** Enhanced visual hierarchy powered by Google Fonts and FontAwesome icon integrations.

---

## Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Custom Properties, Flexbox, CSS Grid)
* **Icons & Assets:** FontAwesome 6.4.0
* **Development Environment:** Visual Studio Code with Live Server support

## Setup & Installation

1. **Clone or Download the Repository:**
```bash
git clone https://github.com/your-username/portfolio.git

```


2. **Open in Code Editor:**
Launch Visual Studio Code inside the project folder:
```bash
code .

```


3. **Run Locally:**
* Install the **Live Server** extension in VS Code.
* Right-click on `index.html` and select **Open with Live Server**.
